Edge TTS သည် Microsoft ၏ browser-side လမ်းကြောင်းကို တိုက်ရိုက်သုံးသည်။ Microsoft Edge browser ပေါ်တွင် အကောင်းဆုံးအလုပ်လုပ်ပြီး၊ Chrome/Firefox/Safari အချို့တွင် Microsoft ၏ ချိတ်ဆက်မှု ကန့်သတ်ချက်ကြောင့် ချိတ်ဆက်၍ မရနိုင်ပါ (connection error)။ မရပါက အောက်ပါ Gemini TTS ကို ပြောင်းသုံးပါ။
API key ကို Google AI Studio မှ ရယူနိုင်သည်။ key ကို ဤ browser tab အတွင်းသာ အသုံးပြုပြီး မည်သည့်နေရာသို့မျှ သိမ်းဆည်း/ပို့လွှတ်မှု မရှိပါ (page ပိတ်လိုက်ပါက ပျောက်သွားမည်)။ Gemini TTS တွင် "သီဟ/နီလာ" ဟူသော အမည်တိုက်ရိုက် အသံမရှိသေးပါ — အထက်ပါ voice များထဲမှ ရွေးချယ်ရမည်။
